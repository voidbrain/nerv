## Improvement proposals (not accepted work)

1. **Turn on Dependabot alerts and a code-scanning workflow.** The value is an early notice of vulnerable dependencies. It costs minutes, and the only risk is noise. This is a repository setting, so it's your decision.
2. **Add Node 26 to the CI matrix.** Your bases run 26 while CI tests 24, and a single job would catch version-specific breakage. It costs one more CI job per run.
3. **The template's freshness check could resolve `template.path` from the main worktree** (`git rev-parse --git-common-dir`), so agents working in worktrees don't get a false "template not found". This belongs to the harness template first, per the template's change rule.
