# Archive

Dated history: closed backlog records, one file per year (`backlog-<year>.md`, in closing-date order), older evidence moved out of active records (`evidence-<year>.md`, under each record ID) and finished plans (`plans/`). These files preserve evidence as it was; they are not current status and do not override [AGENTS](../../AGENTS.md), the [backlog](../BACKLOG.md) or its [rules](../BACKLOG-RULES.md). Historical archives keep their original table formats.

Each yearly backlog file starts with a generated Monday–Sunday closure index. Run `npm run backlog:recap` after moving records; `npm run check:recap` and `npm run check:backlog` verify the index and preserve historical record lines. <!-- project -->

The backlog header keeps only its latest reconciliation; earlier ones move, newest first, to `reconciliation-<year>.md` ([2026](reconciliation-2026.md)). <!-- project -->

[Historical design inputs](design-inputs/README.md) preserve mixed sources whose valid intent must not be confused with superseded details. Current target/status remain in the active architecture and backlog. <!-- project -->
