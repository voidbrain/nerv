# Archive

Dated history: closed backlog records, one file per year (`backlog-<year>.md`, in closing-date order), and finished plans (`plans/`). These files preserve evidence as it was; they are not current status and do not override [AGENTS](../../AGENTS.md), the [backlog](../BACKLOG.md) or its [rules](../BACKLOG-RULES.md). Historical archives keep their original table formats.

Each yearly backlog file starts with a generated Monday–Sunday closure index. Run `npm run backlog:recap` after moving records; `npm run check:recap` and `npm run check:backlog` verify the index and preserve historical record lines. <!-- project -->
