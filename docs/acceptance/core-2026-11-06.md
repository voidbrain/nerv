## Reproduction

Install locked dependencies, then run `npm run typecheck`, `npm test`, `npm run build`, `npm run test:headless` and `npm run test:browser`. Chrome/Chromium is required; `CHROME_BIN` can select it. `NERV_BROWSER_ARTIFACTS=/tmp/nerv-core-browser npm run test:browser` retains screenshots. CI validate runs the browser checks and uploads its `angular-browser` artifact. Test identities/content are invented; the browser uses an isolated profile and in-memory store, and process tests use temporary disk-backed homes.

Local build/browser/process commands required permission to launch local subprocesses and bind loopback servers beyond the execution sandbox. A sandboxed build aborted and sandbox-restricted networking is not treated as product failure. The successful runs above used the required execution permissions.

## Operating boundary and exclusions

The supported local operating procedure remains [Installation](../INSTALL.md): build before serving/updating, one user service owns the process, `doctor` gives diagnostics, and graceful stop/restart preserves local data. No hosted production deployment is provisioned. Local SQLite inbox delivery does not establish a phone notification.

This acceptance does not close target-host login/logout installation (F-009), native permission/banner/signing work (F-011/F-015), PWA/offline/push or generated UI (F-004), Telegram command coverage (F-056), load resilience (F-013), or backup/restore acceptance (F-062).
