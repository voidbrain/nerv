# Acceptance evidence

Dated observations for specific revisions, test methods and devices. Reports preserve what was actually checked; passing mocks or CI does not establish a physical notification, service installation or production signature. Current status stays in the [backlog](../BACKLOG.md).

The [review register](../reviews/README.md#acceptance-evidence) links every report, its observation date and the next acceptance condition. Earlier evidence is retained when later reports narrow or supersede its applicability.
