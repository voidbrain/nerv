# F-159: Grover off and on, with no new grant

Owner steps for [F-159](https://github.com/voidbrain/nerv/blob/backlog-views/docs/BACKLOG.md#f-159) (step F-159-T05). Run every command in a Terminal on the owner's Mac (NERV-01), with Grover's hub registered and at least one of its read tools granted, as in the [F-123 page](f123-t02-grover-tools.md). The [remote MCP guide](../guides/remote-mcp.md#modules) explains modules.

## 1. The installed service has modules

```bash
nerv modules
```

Expected: one line per module, for example `FPVBuddy (fpvbuddy) · on · reachable · 9 tool(s)`, `Cooking (cooking) · on · …` and `Grover (grover) · on · reachable · N tool(s)`. `Unknown command` instead: run `nerv update` once, then step 1 again.

## 2. Grover on: the question uses a Grover tool

```bash
nerv chat "quali piante ho?"
```

Expected: a line like `· grover.grover_overview → grant` and an answer naming your plants.

## 3. Grover off: no Grover tool

```bash
nerv modules off grover
nerv chat "quali piante ho?"
grep -c '"server": "grover"' ~/.nerv/config.json
```

Expected: the first command says `Grover is off: … its N grant(s) and its data are kept`; the chat answer has no `· grover.` line (Misato says it cannot see the plants now); the `grep` prints the same number of grants as before (not 0). On the full dashboard (`nerv open full`, or the full dashboard link on the simple page) the Modules panel shows Grover as Off.

## 4. Grover on again: it works with no new grant

```bash
nerv modules on grover
nerv chat "quali piante ho?"
```

Expected: `Grover is on: its tools are offered again as granted, no new grant needed.`, then the same `· grover.… → grant` line as in step 2. You ran no `nerv tools grant`.

## 5. The dashboard switch

Open the full dashboard as in step 3, find the Modules panel, untick the work-across-projects module, then tick it again.

Expected: unticked, the "Work across projects" card disappears; ticked, it comes back. Switch to the Eva theme and Italian: the panel reads "Cavi ombelicali · moduli" with "Collegato" / "Espulso".

Tell the agent "ok", or what looked different at which step; it records the evidence in F-159 and closes it.
