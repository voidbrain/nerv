# Angular bilingual workspace acceptance — 6 November 2026

Implementation and acceptance: [PR #157](https://github.com/voidbrain/nerv/pull/157).

Scope: F-010 and defects B-030–B-033 discovered during acceptance. Tested the built Angular workspace through the real local HTTP server and an in-memory SQLite store; no personal data or installed services. Source baseline: main `7129b88` plus the candidate changes on `test/bilingual-browser-acceptance` (a dirty working-tree build, not an unchanged main build).

Reproduce with a full dependency install, `npm run build`, then `npm run test:browser`. Requires Chrome/Chromium; set `CHROME_BIN` if it is outside the standard executable paths. Set `NERV_BROWSER_ARTIFACTS` to a directory to keep screenshots. CI validate runs the command and uploads the `angular-browser` artifact. The runner uses a temporary browser profile and a fresh in-memory database.
