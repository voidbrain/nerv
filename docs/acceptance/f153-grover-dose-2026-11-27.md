# F-153: NERV checks whether a Grover pot needs a dose

Owner steps for [F-153](https://github.com/voidbrain/nerv/blob/backlog-views/docs/BACKLOG.md#f-153) (steps F-153-T05, after F-153-T03 and F-153-T04). Run every command in a Terminal on the owner's Mac (NERV-01), with Grover's hub registered as in the [F-123 page](f123-t02-grover-tools.md). The skill only reads: it never starts a dose. Do steps 3 to 5 only after the night evaluation (F-153-T03) has recorded a report in F-153 saying the skill beats the baseline on the held-out cases; the agent tells you when.

## 1. The installed service has the skill and the run-time matcher

```bash
nerv update
cd ~/.nerv-app && node -p "require('./skills/grover-dose.json').manifest.version"
```

Expected: `1.1.0`.

## 2. Grant the three reads

```bash
nerv tools grant grover/grover_overview
nerv tools grant grover/grover_readings
nerv tools grant grover/grover_feed_preview
nerv tools | grep grover
```

Expected: each grant is `read` (Green); the three tools show as granted. Do not grant `grover/grover_feed`: the skill does not need it.

## 3. Stage the skill and show the night report

```bash
nerv skills stage ~/.nerv-app/skills/grover-dose.json
nerv skills list
```

Expected: `grover-dose` with version `1.1.0` and status `staged`. Staged means it does not apply yet: `nerv chat "serve una dose al vaso 2?"` still answers without a "Skill:" line.

Then evaluate in your own data home with the filled suite the night wrote (the path is in the F-153-T03 record, `grover-dose-26b.json` in the night's OUT folder):

```bash
nerv skills evaluate grover-dose 1.1.0 <OUT>/grover-dose-26b.json gemma4:26b
```

Expected: `"eligibleForPromotion": true` and `"escalation": {"ok": true, ...}`. If it says false, stop: do not promote, tell the agent.

## 4. Promote (your decision)

```bash
nerv skills promote grover-dose 1.1.0 --owner-approved --model gemma4:26b
```

Expected: status `active`. To undo at any time: `nerv skills rollback grover-dose --owner-approved` (or `retire`).

## 5. Try it on the tent

```bash
nerv chat "controlla se è richiesta un'altra dose"
nerv chat "does pot 2 need another dose?"
```

Expected: the reply starts with "Sì, serve una dose al <vaso>" or "No, non serve una dose al <vaso>" (in English: "Yes, a dose is needed for <pot>" or "No dose needed for <pot>"), gives the numbers it read against the phase limits, and ends with:

```
Skill: Grover: serve una dose? (grover-dose 1.1.0)
```

No approval card appears and no feed starts. If you ask it to give the dose, it says it cannot start a feed. Note any answer that contradicts the pot's real readings: that is a result too.

Tell the agent the outcome of each step (paste the outputs of steps 3 and 5); it records the evidence in F-153 and closes it or retires the skill.
