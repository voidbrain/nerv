# NERV Agency style guide

NERV Agency is a local proactive personal agent. Its symbol (owner choice, 2026-11-04) is an original inverted triangle with seven almond eyes in rows of 4, 2 and 1: `web/public/mark.svg`, used for the browser icon and the native menu. The web sidebar shows `web/public/brand.svg`, an original half leaf beside the same triangle. Both are project-local geometry in one colour, dark NERV red `--mark` (#d4002a, 3.15:1 on `--bg`, above the 3:1 graphics minimum; deeper reds fall below it), with eyes and veins cut out. An SVG loaded as an image cannot read CSS variables, so the files carry the literal value and test/brand.test.ts keeps it equal to the token. They are evocations, not copies: never ship the Evangelion NERV leaf or SEELE mask artwork, which are third-party trademarks. No raster, stock or generated concept art is shipped as the mark.

Use the tokens in `web/src/styles.css` as the palette source of truth: dark navy surfaces, pale text, muted labels and seafoam actions. The marks are one colour. Use system sans-serif for controls and Georgia italic for the introductory line. No remote fonts. Generous spacing, visible focus, persistent labels and explicit error messages. Main copy is calm and concrete. Avoid claims of connected devices or delivered phone notifications unless observed.

The workspace contains stable navigation, reminders, local inbox and diagnostics. GenUI foundations use validated Web Component descriptions; it does not replace navigation or inject executable code. Distinguish planned, configured, connected, observed and failed states.

English is the default UI language; Italian is selectable (the language switcher stays). Keep messages in web/src/i18n.ts with matching keys. User reminder content is never translated automatically. Browser date inputs and formatted dates use browser local time, explicitly labelled; server configuration defaults to Europe/Rome for future scheduling semantics. Changing the UI language does not reinterpret stored UTC deadlines. CLI command names and raw doctor fields remain technical English.

The status card uses the existing theme tokens through a Shadow DOM. Shadow DOM encapsulates styles; it is not a security boundary. The current surface is deterministic, not LLM-generated. Preserve text escaping and bounded descriptions in every renderer.

The native menu uses a monochrome template drawing of the seven-eye triangle, with English default and Italian selection. The scrollable menu displays at most five pending reminders and Mac-local dates. Quit companion leaves the daemon running. Native pairing uses a SecureField; never show or copy the administrative bearer token into the app. Local forget and server revocation are distinct. Native/system error details may retain the OS language.

Notification enablement says “from now”; denied/failed permissions remain visible. Stop NERV Agency uses a destructive confirmation; Quit companion is a separate action. Service loaded, daemon connected and login enabled/approval-required must be shown as distinct states. Never present OS notification submission as proof the user saw a banner.

The NERV dashboard (`web/public/dashboard/`) has its own themes (EVA Full, EVA Basic, neutral, light, terminal) defined as tokens in its stylesheet. In live mode, a panel without real data says *planned · not connected yet*; it never shows the simulation's invented numbers next to real ones.
