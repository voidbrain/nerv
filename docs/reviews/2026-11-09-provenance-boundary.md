The existing policy already maps tainted external effects to Pattern Blue and tainted local work to EVA-03. It did not carry trust from MCP results to the next action. MCP dispatch consumes its gate grant and marks the context tainted before control returns to the coordinator, including lost replies and error text. Later local outside-code calls select EVA-03 and are rejected because no sandbox exists. Deterministic built-in executors continue to run through their existing grants; EVA-03 is not a claim that those functions run in an OS sandbox. Approved facts inherit sortie taint; duplicate facts merge taint monotonically. Consolidation derives summary/fact taint from all contributing exchanges. A one-time migration marks unlabelled legacy planner context and model-written facts tainted, preserving event/history evidence. Legacy summaries and reminder text without reliable item provenance are conservative tainted inputs.

Alternatives considered: prompt-only source tags cannot enforce the gate; an in-memory flag loses provenance on restart; blanket rejection of every deterministic built-in prevents useful owner-reviewed local work without creating isolation. The chosen durable source labels reuse the ledger and memory rather than introduce another authority. The additive summary column preserves old data and FTS identities. The golden quarantine evaluation deliberately changes from grant to rejection: outside code requiring EVA-03 cannot execute until F-049 supplies confinement.
