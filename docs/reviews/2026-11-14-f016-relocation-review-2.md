## Resolved from the 13 November review

### Blocking findings (1–4)

1. **Partition & lease renewal**: Renewals via `POST /kaji/lease/renew` require a `base-key`-signed standby acknowledgement persisted in host-local `standby_lease_state`. A partitioned `main` host self-fences locally within `55_000` ms (`LEASE_TTL_MS - LEASE_SAFETY_MARGIN_MS`). Standby enforces a monotonic `process.hrtime.bigint()` wait of `65_000` ms when every enrolled unrevoked peer and worker base acknowledges `coordinatorEpoch = E + 1` pre-activation, or `300_000` ms (`LEASE_TTL_MS + 2 * KAJI_CLOCK_SKEW_MS`) whenever any unrevoked peer or outbound-only `GET /kaji/worker` destination has not acknowledged `E + 1`. Single-base / no-standby relocation requires root-signed `revoke` or `--confirm-old-host-down` plus the `300_000` ms horizon.
2. **Per-base agency state separation**: Coordinator state and per-base state are explicitly **kept separate**. Non-main hosts do not run coordinator tick/watch/brief/outbox/resumer loops, fail closed on `Runtime.chatOnce` instead of falling back locally, and write replicated batches into separate `coordinator-standby.sqlite` rather than merging into `nerv.sqlite`. Exact `deliveries.rowid` and UUID `id` values are preserved across the 5-step quiesce-merge-swap (`worker_approvals.persisted_decision` + `hasApproval` `LEFT JOIN approvals` across `Store.expire()`, `cancelWorker()`, and `releaseWorker()`, plus preserving `PRAGMA user_version` and external `~/.nerv-lifecycle/journal.sqlite`, `~/.nerv-bootstrap/journal.sqlite`, and `native-auth.sqlite` untouched at their own paths).
3. **Table, file, cursor & quarantine inventory**: Removes non-existent `state`, `telegram.cursor`, `worker_outbox_jobs`/`events` (noting `deliveries_v5` and `kaji_runs` migration artifacts), includes all live `nerv.sqlite` tables (`reminder_times`, `kaji_outbox_pilots`, `watch_steps`, `watch_cursors`, `worker_outbox_attempts`, `worker_outbox_cancels`, `worker_outbox_reconciliations`, `worker_legacy_outbox`, `provenance_migrations`, `worker_approvals`, `worker_cancellations`, `worker_releases`, `root_migrations*`) and external `.sqlite`/config/secret files, preserves native `Store.inboxPage(after, limit, afterId)` cursors, replicates Telegram `State` (`offset`, `inbox`, `cards`, `messages`, `brief`) into `coordinator_state` at `save()` checkpoints with `TelegramChannel.this.state` rehydration on promotion, and fixes quarantine to join incomplete `kaji_outbox` (`done IS NULL`) against `worker_outbox_attempts` lacking terminal `worker_outbox_reconciliations` rows.
4. **Effect-boundary fencing checks**: Covers `nervous-process.ts` (`tick`/`expire` + parent IPC lease sync), `new Store(...)` constructor `deliverApproval` active-mode guard, `Store.dispatchPushReminders`, `Runtime.startOutbox`/`startResumer`/`closeInterrupted`/`Watch.interrupt`, `Runtime.chatOnce` fail-closed non-main behavior, authority-scoped `Store`/`Ledger`/`Memory` (preserving worker execution on enrolled workers via `WorkerLease`), coordinator vs peer Kaji HTTP handlers (`/kaji/chat`, `/kaji/relay`, read-only `/kaji/sortie`, `/kaji/verdict`, `/kaji/approvals/pending`, `/kaji/decide`, legacy `/kaji/run`, `/kaji/replicate`, `/kaji/epoch-push`, plus `/kaji/lease/renew` without stale-lease deadlock), `TelegramChannel` (`poll()`/`local-fallback` + shared-vs-separate bot handling), coordinator vs host-local REST/SSE routes (`src/server.ts`), and direct-SQLite CLI writes vs `kaji import`, `workers cancel/release`, and `root`-gated loopback HTTP `POST /api/kaji/lease/rearm` (keeping `/rpc` read-only).

### Should-fix findings (1–5)

1. **Sleep & effect-boundary rechecks**: `isActiveCoordinator(now)` checks both wall clock (`Date.now() < lease_expires_at`) and awake monotonic clock (`process.hrtime.bigint() < leaseExpiresMonoNs`) synchronously at every coordinator effect boundary in both `serve` and `nervous-process.ts`.
2. **Delayed in-flight requests**: Combines pre-activation HTTP `/kaji/epoch-push` + WebSocket `E + 1` push, `X-Kaji-Lease-Expires-At` validation (`KAJI_CLOCK_SKEW_MS = 120_000`), `worker.ping` refresh for open worker sessions, and the `300_000` ms conservative horizon when any outbound-only or offline unrevoked destination has not acked `E + 1`.
3. **Worker protocol naming & ledger methods**: Uses `coordinatorEpoch` / `coordinatorFence` distinctly from `worker_sessions.epoch` / `worker_jobs.fence`, replaces `Ledger.consume` with `Ledger.authorize` / `grants.used`, and aligns `sorties.status` (`'open' | 'done' | 'failed' | 'revoked'`) and `Watch.interrupt()`.
4. **Lost laptop & `lease-rearm` authority**: Specifies the offline USB backup of `key-of-nebuchadnezzar.enc` + passphrase for signing both `revoke` and replacement `main` (`E + 1`), sole-base self-lease fallback, credential rotation, `[root migration](../decisions/node-root-migration.md)` fallback, and `base-key` signing + `root`-token loopback HTTP for `nerv kaji lease-rearm --confirm-sole-coordinator`.
5. **Registry merge & local `last_seen`**: `registry` and `registry_roots` merge monotonically by `serial` without rollback; `kaji_seen` and `registry_seen` (heartbeat `last_seen` tables) and in-memory `Nonces` stay host-local.
