# Gauntlet coverage review — 2026-11-25

First written by Gemini against `main` `bebbfd0c` with the gauntlet-protocol 0.9.1 pin; reviewed and updated by Claude the same day against `main` `767f8111` and the gauntlet-protocol 0.11.1 catalog ([F-120-T01](../../work/tasks/F-120-T01.json), parent [F-120](../../BACKLOG.md#f-120)).

## Scope and baseline

- **Pinned protocol release on `main`:** `@voidbrain/gauntlet-protocol@0.9.1`, 8 common packs (76 cases).
- **Catalog this review is checked against:** gauntlet-protocol [v0.11.1](https://github.com/voidbrain/gauntlet-protocol/releases/tag/v0.11.1). v0.10.0 released the domain packs `coding`, `logic-math` and `embedded`; v0.11.0 released `italian-quality`, `cad-3d` and `code-review` (each pack `@1.0.0`); v0.11.1 fixes runner error handling. NERV adopts 0.11.1 in F-120-T03 ([PR #749](https://github.com/voidbrain/nerv/pull/749), open when this review was updated).
- **NERV system pack:** [`evals/gauntlet/system-v1.json`](../../../evals/gauntlet/system-v1.json) (`nerv-system-flows@1.2.0`), 8 flows (`policy`, `ledger`, `conversation`, `channels`, `bases`, `stress`, `browser`, `script-plans`). Each flow is a registered runner that runs fixed test files from [`evals/suite.json`](../../../evals/suite.json) with no model; `tools/gauntlet-adapter.mjs` passes a flow only when every test passes, none is skipped and the count reaches the group's `minimumTests`. The proposed cases below use the same grader.
- **Capability index:** [`docs/test-capability-index.md`](../../test-capability-index.md) on main has 10 areas with 0 mapped cases; with the 0.11.1 pin (PR #749) 5 remain at 0: `backlog-management`, `estimation`, `research`, `audio-video`, `scheduling-time`.
- **Classes used below:**
  1. **NERV-specific case needed (propose for `F-120-T02`):** model-facing or capability-gated NERV system flow whose tests no `system-v1.json` flow runs yet.
  2. **Already covered in `nerv-system-flows`:** a flow in `system-v1.json` already runs the feature's tests.
  3. **Covered by a gauntlet domain pack:** a general model capability owned by `voidbrain/gauntlet-protocol`; NERV consumes it through its pin (F-120-T03).
  4. **No model-facing behaviour:** deterministic CLI, UI layout, build, CI, harness, refactor, documentation or evaluation-record work that needs no Gauntlet case.

The general capabilities this review first listed as requests are released; NERV consumes them through the 0.11.1 pin in F-120-T03 (PR #749). None of them is NERV work.

1. **`coding@1.0.0`** (v0.10.0, `area: "coding"`, 4 cases): Python and TypeScript tasks graded in a container sandbox.
2. **`embedded@1.0.0`** (v0.10.0, `area: "embedded"`, 8 cases): Arduino/ESP32 compile-graded sketches and Raspberry Pi tasks.
3. **`logic-math@1.0.0`** (v0.10.0, `area: "math"` and `"logic-planning"`, 8 cases): exact-answer arithmetic, constraint and puzzle tasks.
4. **`italian-quality@1.0.0`** (v0.11.0, `area: "language-translation"`, 6 cases): Italian summary, rewrite and register tasks.
5. **`cad-3d@1.0.0`** (v0.11.0, `area: "cad-3d"`, 10 cases): slicer, material and tolerance questions and OpenSCAD build-and-measure tasks.
6. **`code-review@1.0.0`** (v0.11.0, `area: "code-review"`, 6 cases): seeded-defect diff review graded by `defects-v1`.

Still open upstream, not released: gauntlet-protocol F-021 (`image-generation-v1`, area `audio-video`, design decision first) and F-022 (packs or recorded skips for `estimation`, `research`, `scheduling-time`, `backlog-management`).
