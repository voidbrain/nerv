- **Capability index:** [`docs/test-capability-index.md`](../../test-capability-index.md) (84 mapped cases across 9 covered areas and 10 areas with 0 mapped cases).
- **Classes used below:**
  1. **NERV-specific case needed (propose for `F-120-T02`):** Model-facing or capability-gated NERV system flow not yet represented in `evals/gauntlet/system-v1.json`.
  2. **Already covered in `nerv-system-flows`:** Model-facing NERV feature whose regression and acceptance checks already run inside one of the 8 existing `system-v1.json` cases.
  3. **General capability (`gauntlet-protocol` request / `F-120-T03`):** Domain or model capability owned by `voidbrain/gauntlet-protocol` rather than NERV's system pack; NERV adopts it when the upstream release is pinned in `F-120-T03`.
  4. **No model-facing behaviour:** Deterministic CLI, UI layout, build, CI, harness, refactor, or documentation feature that uses no model judgment and needs no Gauntlet case.

2. **`embedded-v1` (`area: "embedded"`):** Arduino/ESP32 compile-graded sketches against pinned cores and Raspberry Pi static/AST-graded Python tasks (`gauntlet:F-016`).
3. **`logic-math-v1` (`area: "math"`, `"logic-planning"`):** Exact-answer arithmetic, constraint, puzzle and scheduling tasks (`gauntlet:F-017`).
4. **`italian-quality-v1` (`area: "language-translation"`):** Italian summary, rewrite and register-control tasks graded by `rubric-v1` (`gauntlet:F-018`).
5. **`cad-3d-v1` (`area: "cad-3d"`):** Exact-answer 3D-printing slicer/material/tolerance questions and OpenSCAD build-and-measure tasks rendered in the container sandbox (`gauntlet:F-019`).
6. **`code-review-v1` (`area: "code-review"`):** Seeded-defect unified diff review tasks graded by `defects-v1` with bounded line spans and false-positive caps (`gauntlet:F-020`).
