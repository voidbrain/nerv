## What it is

A Python client for a "code mode" agent framework. Instead of JSON tool schemas, the caller passes live objects (functions, classes, SDK clients) into the agent's scope; the model writes Python against them, and the framework checks the declared return type of each call (`agent.call(str, …)`). Execution happens on a separate server (the hosted Symbolica platform or a self-run `agentica-server`), which this repository does not contain.

## Decision

Not adopted as a dependency: NERV is Node 24 TypeScript, the SDK is Python 3.12–3.13 only and needs a separate server, its sandboxing is not visible in this repository, and live object references give the model whatever authority those objects have, with no gate per call. Three ideas are kept as NERV features, each behind the existing MAGI gate, tool effect classes and EVA isolation:

| Idea | NERV today | Record |
|---|---|---|
| Typed results: each call declares the shape it returns and the boundary checks it | Tool arguments are described in prose (`toolDocs` in `src/executors.ts`); results are `unknown` | [F-111](../BACKLOG.md#f-111) |
| Script plans: the model writes one short script over several read calls instead of N separate tool calls | One tool call per planner step | [F-112](../BACKLOG.md#f-112) |
| Capability scope: the model sees a compact index of tool subjects and asks for a subject's details when it needs them | Every tool's full doc is in the planner prompt | [F-113](../BACKLOG.md#f-113) |

Revisit when one of these records needs an external runtime, or the project publishes its server and sandbox with a release that can be pinned and reviewed.
